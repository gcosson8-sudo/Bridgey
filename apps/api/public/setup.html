Bringup

One-host deployment

Bridgey runs as one API node with local Playwright sessions, one Postgres instance, and an HTTPS proxy in front. 

docker compose up -d --build

1. Environment

Required
  1. Copy .env.example to .env.
  2. Set BRIDGEY_MASTER_KEY to a 32-byte base64 key.
  3. Set BRIDGEY_API_KEYS and BRIDGEY_ADMIN_KEYS to strong random values.
  4. Set BRIDGEY_SITE_ADDRESS to :80 for local HTTP or your public domain for HTTPS.

2. Start the stack

Compose 
docker compose up -d --build

Caddy listens on ports 80 and 443. The API remains internal on port 3000.

3. Allowlist your first domain

Admin 
curl -X POST http://localhost/admin/allowlist \
  -H 'content-type: application/json' \
  -H 'x-bridgey-admin-key: YOUR_ADMIN_KEY' \
  -d '{"action":"add","domain":"example.com"}'
